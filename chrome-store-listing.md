## Long Description (paste into the Chrome Web Store "Description" field)

ReplyTonic brings 7 AI-powered communication tools directly into any website — no switching tabs, no copy-pasting.

**7 AI Tools in One Extension:**

✏️ **Rewrite** — Paste any message, get 3 polished versions in 2 seconds. 6 tones: Professional, Casual, Formal, Friendly, Direct, Empathetic. Works in 25+ platforms.

💬 **Reply Generator** — Got a message you need to respond to? Paste it in, pick a tone, get the perfect reply instantly.

📋 **Summarize** — Long email threads, Slack messages, or articles → clean bullet-point summary in seconds.

✅ **Grammar Check** — Finds and fixes grammar, spelling, punctuation, and awkward phrasing. Shows exactly what changed.

🤖 **Humanize AI Text** — AI-written drafts sound robotic. This tool rewrites them to pass detection and sound authentically human.

🔍 **AI Content Detector** — Paste any text to see the probability it was AI-generated, with confidence score and flagged phrases.

📄 **Plagiarism Checker** — Get an originality score, risk level, and flagged phrases for any text before you submit or publish.
